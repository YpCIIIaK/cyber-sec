# 🛡️ CyberPath

Бесплатная интерактивная платформа для изучения кибербезопасности в стиле TryHackMe — **полностью своя, без регистрации и без бэкенда**. Всё работает в браузере, прогресс сохраняется локально.

## ✨ Возможности

- **14 курсов** от новичка до продвинутого уровня — всё на **Windows** (без Linux)
- **Контент заземлён на реальные стандарты** (см. раздел «Источники»): OWASP Top 10, MITRE ATT&CK, NIST SP 800-61, CIS Benchmarks, SPF/DKIM/DMARC и др. — никаких выдуманных фактов
- **Прогрессия по сложности**: продвинутые курсы открываются только после прохождения предпосылок на 100%
- **Комнаты (rooms)** с теорией и заданиями, открываются последовательно
- **Задания-квесты**: вопросы, выбор, сопоставление, порядок, поиск флагов `CYBER{...}`, задание дня
- **Живая песочница-терминал Windows** — эмулятор cmd/PowerShell с виртуальной ФС, «сетью» и реестром (`dir`, `type`, `findstr`, `reg query`, `certutil -decode`, `nmap`, `nslookup`, `ping`, `Get-Service` и др.), Tab-автодополнение, многошаговые квесты-машины
- **Система прогрессии**: XP (со штрафом за подсказки), уровни, серии дней, **11 достижений**, сертификаты за курс
- **Два языка (RU/EN)** — переключатель в шапке: интерфейс, каталог, глоссарий, достижения и звания переводятся (тексты уроков пока на RU)
- **16 званий** от Новичка до Легенды, дашборд с графиками (XP, радар, календарь), режим интервального повторения, шеринг-карточка профиля
- **Светлая и тёмная темы**, плавные анимации XP, экспорт/импорт прогресса, поиск и фильтры в каталоге
- **PWA**: устанавливается как приложение и работает офлайн (service worker)
- **Дорожная карта** «Путь» — граф курсов по ярусам сложности
- **Глоссарий** (~50 терминов) и **финальные экзамены** курсов с сертификатами
- **Командная палитра** (Ctrl/⌘+K) для мгновенного перехода, ранги/звания, конфетти, горячие клавиши (?)
- **Доступность**: skip-link, focus-visible, навигация с клавиатуры, prefers-reduced-motion
- **Сохранение прогресса локально** (localStorage) — никаких аккаунтов и слежки

## 📖 Источники (на чём основан контент)

Материал курсов сверен с общепризнанными отраслевыми стандартами и фреймворками:

- [OWASP Top 10](https://owasp.org/www-project-top-ten/) — риски веб-приложений
- [MITRE ATT&CK](https://attack.mitre.org/) — тактики и техники (14 тактик Enterprise), Pyramid of Pain (D. Bianco)
- [NIST SP 800-61](https://csrc.nist.gov/pubs/sp/800/61/) — жизненный цикл реагирования на инциденты (4 фазы)
- [CIS Benchmarks](https://www.cisecurity.org/cis-benchmarks) — безопасная конфигурация (Level 1/2)
- SPF / DKIM / [DMARC](https://dmarc.org/) — аутентификация электронной почты

## 🚀 Запуск

Никакой сборки не требуется — это чистые HTML/CSS/JS.

```bash
# просто откройте index.html в браузере, или поднимите локальный сервер:
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## 🗂️ Структура

```
index.html        — оболочка и навигация
css/styles.css    — тема (бело-оранжевая) и все стили
js/data.js        — контент: курсы, комнаты, задания, достижения
js/terminal.js    — эмулятор терминала (песочница)
js/app.js         — ядро: роутинг, прогресс, XP, рендер
```

## ➕ Как добавить свой курс

Добавьте объект в массив `COURSES` в `js/data.js`. Каждый курс содержит `rooms`, каждая комната — `tasks`. Типы заданий:

- `info` — «прочитать» (кнопка «Понятно»)
- `question` — вопрос с проверкой ответа (`answers: [...]`)
- `flag` — поиск флага (обычно `caseSensitive: true`, часто с `sandbox: true`)
